# Fivem-Playerblips

/pblips – Spieler auf der Karte anzeigen

Mit dem `/pblips-Befehl können Administratoren alle aktuell verbundenen Spieler übersichtlich als Blips auf der Karte anzeigen lassen. So behältst du jederzeit den Überblick über die Positionen der Spieler und kannst schneller auf Situationen reagieren.

Funktionen:

Zeigt alle Spieler als Blips auf der Karte an

Nur für Administratoren nutzbar

Hilfreich zur Überwachung und Unterstützung im Support

Einfach per Befehl aktivierbar und deaktivierbar

Befehl: /pblips
